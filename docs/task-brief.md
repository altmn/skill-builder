# Task contract for Skill Builder

## Outcome

Provide a Codex-first portable skill that creates other skills, audits existing skill projects, and answers skill-building questions using the supplied knowledge base in full. The two required routes are `skill-builder-create` and `skill-builder-audit`. Deliver a complete installable archive and a separate source archive suitable for later GitHub preparation; do not install or publish during this task.

## Inputs and outputs

Inputs are a user task/examples, an explicitly selected skill project or archive, host/scope requirements, and existing authorization. The immutable knowledge source is the exact supplied ZIP, pinned in the runtime helper. Creation produces a task-specific project and evidence; audit produces a separate report/coverage/findings workspace; explanation produces a source-linked answer. Helpers perform deterministic preparation and validation, while the agent finishes semantic work.

## Architecture and scope

Use the resource-assisted profile. Scripts are justified for exact source preservation/retrieval, all-rule ledger generation, bounded static inventory, reviewed original validators, and deterministic packaging. Keep host adapters explicit. Network research is an agent capability for current primary documentation; the CLI itself is offline. External publication is a conditional workflow effect that requires authorization, not a default CLI behavior.

There is no custom installer, automatic update, daemon, persistent application database, authenticated browser integration, telemetry service, paid-model dispatcher, or general-purpose target-code executor. Local project/report outputs persist at the explicit destination. They do not imply a stateful service or migration subsystem.

## Independent acceptance

- The embedded archive equals the supplied ZIP byte for byte, and all 182 substantive members match individual hashes/sizes.
- Every one of the 99 original rules has a concrete procedure owner and an explicit applicability/evidence contract; no source rule, handbook, catalog, schema, template, tool, historical result, reader, or notice is condensed away.
- The installed runtime has one discoverable skill entrypoint, valid metadata, correct resource references, and honest native command semantics.
- Create/audit helpers preserve existing/unowned files, never execute target code, reject malformed/escaping/tampered inputs, disclose traversal limits, and never invent semantic or host passes.
- Fresh-context agent tasks produce a useful new skill, a source-backed audit of a flawed target, and an accurate focused answer using the full references.
- Package manifests match written members, builds are reproducible for identical input bytes, and validation identifies the actual candidate.
- Honor an already authorized license choice with complete terms and component coverage. Missing license decisions, native-host trials, clean comparative baselines and publication remain visible with their exact consequences.

## Authority and unresolved choices

Local source creation, tests, bounded research, independent review and downloadable packaging are in scope. Installation into live agent roots and GitHub publication are outside this build. Alex has selected MIT for original project and KB material; the effective rc.2 grant and third-party exceptions are recorded in both distributions. The frozen KB and rc.1 receipts retain their historical status. A future publisher must configure actual maintainer/security reporting details and the support tier they will maintain.
