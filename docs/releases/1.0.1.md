# Skill Builder 1.0.1

The main page now shows a realistic project-handoff example and concise prompts for setup, skill creation, source audits, design questions and maintenance. Desktop setup and invocation are clearer, with browser guidance kept within supported host limits.

This release also includes the reviewed pinned validation dependencies and CI maintenance accumulated since 1.0.0, and documents the complete production and existing-installation update workflow.

Create, Audit and Explain behavior is unchanged. The complete knowledge-base ZIP, original 99-rule catalog, third-party terms, historical evidence and published 1.0.0 archives are preserved. Version and release-status metadata are synchronized across the standalone and plugin packages.

The standalone skill, source project and OpenAI plugin ZIPs are separate distributions. The plugin requires local execution in a compatible desktop host. Local checks and publication do not establish native acceptance, comparative task benefit, security certification or OpenAI directory approval. Installation discovery is reported separately from behavioral acceptance.
