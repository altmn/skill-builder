# Skill Builder handoff

Use this record only when a workflow crosses a worker, session, compaction, or meaningful interruption. Keep factual state concise; link the complete evidence.

- Task ID, mode, user outcome, and current scope:
- Exact source paths/revision, dirty/untracked input policy, and content hashes:
- Skill/package identity and actual loaded artifact identity, or reason unknown:
- Host, surface, version, model, policy, tools, and observed capability gaps:
- Decisions already made, who authorized each effect, exact target/data/action, and whether scope still matches:
- Profile, capability modifiers, and justified rule overrides:
- Complete, failed, blocked, not-run, inconclusive, and remaining work:
- Evidence/report/schema paths and coverage denominator/depths:
- Owned output files, workers/processes, private temporary state, and cleanup status:
- External effects attempted, observed remote state, and whether retry is safe:
- Next concrete action, acceptance check, and stale-evidence checks:

A saved statement of approval is evidence to inspect; it does not create new authority. Recheck source identity and the current request before resuming. Never assume a timed-out worker stopped or an unacknowledged write failed.
