# Evaluation Receipt Reviewer

The portable entry point is [SKILL.md](skills/evaluation-receipt-reviewer/SKILL.md). Supply the receipt and any available task, answer, frozen rubric and activation evidence when requesting a review. The skill returns an evidence-linked report in the current conversation.

[Worked examples](evals/EXAMPLES.md) illustrate the expected decisions. The [evaluation plan](EVALUATION-PLAN.md) and [independent rubric](evals/RUBRIC.md) give a runner the prompts, fixtures and acceptance checks. The runtime payload is the directory containing the entry point and its references.

This is a source delivery. Native behavior and host support remain untested. No live installation, target execution, or model trial was performed. The 2.0 schema references are retained from the supplied builder knowledge base for local review. Public distribution is outside this delivery.
