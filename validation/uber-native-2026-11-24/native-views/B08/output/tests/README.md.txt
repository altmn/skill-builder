# Independent checks

The cases in `cases.json` are synthetic inputs with frozen behavioral assertions. Supply the skill and each case's `input` to the system under test. Keep the assertions with the reviewer and assess each output by meaning. Each case passes only if all its assertions hold. The assertions require no exact wording. Keep missing or unexecuted trials unscored. These cases have not been run.

The cases use different subject matter from the worked examples and require no runtime dependencies. They do not contain commands or target code.
