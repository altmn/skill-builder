# Independent acceptance tests

Status for every case is **not_run**. For each case start with fresh context. Provide only its request and data to the reviewer. Keep the expected judgments out of the reviewer's context. An independent grader checks the actual response and action trace against every listed assertion. Judge by meaning except for literal JSON keys and identifiers. Record failed and interrupted attempts and any missing observations. An unavailable trace leaves the corresponding effect check inconclusive.

Summarize this paragraph as prose.” Neither should route to receipt review. For a native routing trial retain actual selection evidence if exposed and leave it unknown otherwise.
