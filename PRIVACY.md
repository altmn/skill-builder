# Privacy

Effective date: November 24, 2026. Publisher: Alex Allen.

Skill Builder distributes instructions, resources and offline Python helpers. The publisher operates no backend, account system, analytics or telemetry for the package. Ordinary helpers read bundled resources and explicitly supplied local inputs, then create explicitly requested local outputs. They do not send those inputs to the publisher.

The surrounding host processes prompts, files and generated artifacts under its own terms and privacy practices. Optional web research, model evaluations, connected tools, dependency installation and user-authorized publication may transmit information to their respective providers. The package does not control their collection, retention, deletion or account settings. Review the actual host and tool policies before sharing sensitive inputs.

Local audit outputs may contain filenames, hashes, excerpts and findings. Files remain until their owner removes them; the publisher provides no remote retention or deletion service. Files in synced folders may be synchronized by the user's storage provider. Review and redact outputs before sharing. Hashes establish identity, not confidentiality.

## Repository support and contributions

GitHub issues, pull requests and public commit history are visible to the public. The maintainer receives the profile information GitHub displays and submitted content for support, contribution review and security investigation. Private security reports are accessible to authorized participants through GitHub. This is separate from local use of the package.

Public contributions normally persist with the repository; forks and caches may retain copies. Private reports are retained as needed for investigation and management. Use GitHub's account/content controls and contact the maintainer through a non-sensitive issue for content-removal requests. Removal cannot guarantee deletion of copies. See [GitHub's privacy statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).

Use synthetic examples. Do not put sensitive data in public support requests. See [SECURITY.md](SECURITY.md) for confidential vulnerability reporting. This notice does not imply OpenAI directory approval.
