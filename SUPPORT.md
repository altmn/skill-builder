# Support

Use [GitHub issues](https://github.com/altmn/skill-builder/issues) for questions, bugs and feature requests. Maintained by [Alex Allen (@altmn)](https://github.com/altmn); no response-time or compatibility guarantee is made.

Include the version, archive hash if available, host/version, Python version, exact command, expected result and actual result. Use a small synthetic example. Do not post credentials, confidential repositories, private conversations or personal data. Historical passes do not establish acceptance of changed packages.

For suspected vulnerabilities, use the private channel in [SECURITY.md](SECURITY.md). For OpenAI account, billing or host problems outside this package, use the provider's support channels.
